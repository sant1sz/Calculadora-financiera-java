# Calculadora Financiera de Oficina
Herramienta de consola desarrollada en Java para operaciones
financieras cotidianas en entornos administrativos.


## Funcionalidades
- Calculadora básica con manejo de errores (división por cero)
- Cálculo de IVA colombiano (19%)
- Aplicación de descuentos por porcentaje
- Cálculo de presupuestos con múltiples ítems

- ## Conceptos aplicados
- Programación orientada a objetos
- Organización en paquetes
- Manejo de excepciones
- Validación de entrada del usuario
- ## Requisitos
- Java 17 o superiores
 ## Ejecución del proyecto
 ```bash
javac -d out src/main/*.java src/operaciones/*.java src/utils/*.java
java -cp out main.Main
```
